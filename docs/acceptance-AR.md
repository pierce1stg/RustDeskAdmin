# دليل قبول عميل الويب

سجل الجلسة: المستويات معلومات / تحذير / خطأ / تصحيح (شريحة “تصحيح” تُفعَّل في الجلسة
الحية دون إعادة اتصال)، الفئات اتصال / ترميز / فيديو / فك ترميز / إدخال / حافظة /
مؤشر / نظام / واجهة. بحث بتمييز أصفر؛ السجل المطوي يعرض العدد فقط. زر المسح يفرغ
السطور فقط — التسجيل يستمر والبطاقة تبقى.

## 1. خريطة سطور السجل

### الاتصال (سليم إذا اكتملت السلسلة في ~3 ثوانٍ)
| السطر | المعنى |
|---|---|
| `hbbs: wss://…/ws/id`، `hbbs connected` | rendezvous وطلب الثقب |
| `relay_response: relay=… uuid=…` | المرحّل أصدر uuid الجلسة |
| `hbbr: …/ws/relay`، `hbbr connected` | قناة الترحيل |
| `encrypted session established` | التشفير قائم |
| `LoginRequest sent` → `login OK, video stream requested` | المضيف قبِلنا |
| `SignedId IdPk at offset N` | أي N (65/66/…) سليم — المستخرج يمسح بطبيعته |
| `relay msg (unhandled fields=21:2)` | ضجيج بروتوكول غير ضار |
| `peer: user@host (OS) WxH` | الهوية والشاشة |
| `cursor_data in / remote cursor applied` | مؤشر المضيف |
| `── connect → PEER` / `── connection lost: …` | حدود الجلسة (الانقطاع لا يمسح السجل) |

### الترميزات
| السطر | المعنى / التصرف |
|---|---|
| `probe: caps gate on (N video mimes)` | بوابة قدرات المحرك مفعّلة |
| `probe: X capped at 720p/1080p/4K` | سقف المحرك؛ الوضع التلقائي لن يتجاوزه |
| `browser codecs: a,b,c` | نتيجة الفحص |
| `codec preference at login: auto -> X (last-good)` | بداية مثبتة النجاح |
| `codec preference: X (prefer=N)` (تصحيح) | تثبيت يدوي / إعداد أُرسل للمضيف |
| `codec X during grace after pin Y` (تصحيح) | انتقال، المضيف يطبّق (حتى 10 ثوانٍ) — طبيعي |
| `host streams X despite manual Y` (تحذير) | المضيف يتجاهل التثبيت فوق 10 ثوانٍ — تحقق هل يدعم Y |
| `codec X excluded: WxH above proven decode cap` (تحذير) | السلّم استبعده — طبيعي |
| `decoder picked X` (تصحيح) | حقيقة المحرك (السلك قد يكذب أثناء الانتقال) |
| `codec steering A -> B` | التلقائي نقَل عند إطارات تالفة — طبيعي |
| `codec fallback exhausted` | السلسلة نفدت — سيئ، افحص الشبكة/المضيف |
| الشريط الأحمر | التثبيت لا يُفك ولا مهرب — زر “عودة للتلقائي” |
| الشريط الأزرق | التلقائي نقَل بنفسه — إعلامي، لا يلزم شيء |

### الفيديو والشبكة
| السطر | المعنى / التصرف |
|---|---|
| `no frames 0.7s/6s after login, re-sending options` | إعادة طلب مبكرة — طبيعي |
| `video stalled (N s) — sent refresh` | المفرد طبيعي؛ المتكرر — افحص الشبكة |
| `auto: A/B -> C/D (kbps, ping, decode/paint)` | قرار السلّم؛ السبب بين قوسين — اقرأه |
| `E 0/3` في الإحصاءات | 3 دلتا تالفة = فقدان في المسار |
| `(−N)` بجانب FPS | إطارات متأخرة مُسقطة (لحاق) |

### الإدخال والحافظة والدردشة
| السطر | المعنى |
|---|---|
| `send key #N down Legacy Ctrl+a` (تصحيح) | تركيبات ورموز؛ وضع Map — مفاتيح فيزيائية (`KeyA`)، و`raw:NN` دون نظام |
| `ui: hotkey …`، `ui: clipboard …`، `ui: switch display` | إجراءات شريط الأدوات |
| `ui: codec/quality/fps/turbo/zoom/…` | تدقيق البقية |
| `ui: chat sent/greeting/close notice` | الدردشة الصادرة ورسائل النظام |

### الأخطاء (رايات حمراء)
`decrypt failed`، `relay decode error + hex`، `SignedId unparseable`،
`connect timed out`، `host closed: …`، `manual codec X failed, no auto fallback`.

## 2. مصفوفة القبول

فواصل 20–30 ثانية بين التبديلات؛ امسح السجل قبل كل حالة.
| # | الإجراء | النجاح |
|---|---|---|
| 1–3 | تلقائي ← VP8 / VP9 / AV1 | `ui:` + `decoder picked`، الشارة تطابق خلال ~10 ثوانٍ، لا شريط |
| 4 | AV1 يدوي على مضيف لا يدعمه | تحذير + شريط أحمر، الشارة تعرض الحقيقة |
| 5 | “عودة للتلقائي” من الشريط | عودة دون إعادة اتصال |
| 6–7 | توربو تشغيل / إيقاف | الإعداد طُبّق؛ استعادة دقيقة (تحقق من المحددات) |
| 8 | إعادة اتصال على التلقائي | `auto -> X (last-good)` فوراً، دون تخبط |
| 9 | دردشة بالاتجاهين | نافذة المضيف ظهرت؛ شارة؛ المواضع survive reload |
| 10 | انقطاع 10–15 ثانية | علامة `connection lost`، إعادة تلقائية، السجل سليم |
| 11 | شاشات (إن وجدت) | `display switched`، و`decoder picked` للدقة الجديدة |

## 3. قراءة الإحصاءات (شريحة ثانية واحدة!)

- **الجوع:** Q بمئات الميلي ثانية + قطرات تنمو + E>0 + kbps في الحضيض. العلاج: جودة تلقائية، خفض المقياس.
- **السكون:** FPS منخفض لكن Q معتدل والقطرات ثابتة وkbps يجري — مجرد شاشة ساكنة، كل شيء بخير.
- **البينغ** = RTT + طابور على قناة الترحيل المشتركة: يكبر مع الترميزات الثقيلة (VP8/9) — هذا bufferbloat، لا “شبكة أسوأ”.
- **المعايير:** فك < 40ms، رسم < 25ms، Q < 120ms.
- **درجات السلّم:** `kbps<1200 أو ping>220` ← 2/15 (القاع)؛ `<3200 أو >110` ← 3/30؛ وإلا 4/60. القاع العميق (1/10) — Q>300 نبضتين متتاليتين. البدء من الصفر يأخذ المسار السريع (~10 ثوانٍ). الصعود يحتاج 6 نبضات + تبريد (ضد التذبذب).

## 4. جغرافيا المنصة (هولندا ↔ خاباروفسك)

الطبيعي: RTT 250–350ms، وkbps يتأرجح 0–1800، وتجمدات مفردة، وبينغ حتى 1600 على VP8/9 مع طابور مختنق.
الرايات: E دفعات، قطرات بالعشرات، decode>40، وQ>300 لدقائق على قاع 1/10.
الخادم خامل دوماً (مُتحقق: LA ~0.15، وhbbr CPU ~0%، وصفر أخطاء واجهة) — الغرق في العمود الفقري، لا في الافتراضية.
