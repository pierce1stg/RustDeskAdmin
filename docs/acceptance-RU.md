# Методичка приёмки веб-клиента

Журнал сессии: уровни Инфо / Предупреждения / Ошибки / Отладка (чип «Отладка» включает
флаг в живой сессии, переподключение не нужно), категории Подключение / Кодеки /
Видео / Декодер / Ввод / Буфер обмена / Курсор / Система / Интерфейс. Поиск с жёлтой
подсветкой, свёрнутый журнал показывает только счётчик. Кнопка очистки чистит только
строки — запись продолжается, карточка остаётся.

## 1. Карта строк журнала

### Подключение (норма, если вся цепочка за ~3 с)
| Строка | Значение |
|---|---|
| `hbbs: wss://…/ws/id`, `hbbs connected` | рандеву, запрос дырки |
| `relay_response: relay=… uuid=…` | релей выдал uuid сессии |
| `hbbr: …/ws/relay`, `hbbr connected` | релейный сокет |
| `encrypted session established` | шифр поднялся |
| `LoginRequest sent` → `login OK, video stream requested` | хост пустил |
| `SignedId IdPk at offset N` | N любое (65/66/…) — экстрактор ищет, так и задумано |
| `relay msg (unhandled fields=21:2)` | безвредный мусор протокола |
| `peer: user@host (OS) WxH` | кто и с каким экраном |
| `cursor_data in / remote cursor applied` | курсор хоста |
| `── connect → PEER` / `── connection lost: …` | границы сессии (обрыв не трёт журнал) |

### Кодеки
| Строка | Значение / действие |
|---|---|
| `probe: caps gate on (N video mimes)` | гейт движка активен |
| `probe: X capped at 720p/1080p/4K` | потолок движка; выше авто не предложит |
| `browser codecs: a,b,c` | итог пробы |
| `codec preference at login: auto -> X (last-good)` | старт с доказанного |
| `codec preference: X (prefer=N)` (debug) | ручной пин / пресет ушёл хосту |
| `codec X during grace after pin Y` (debug) | переход, хост применяет (до 10 с) — норма |
| `host streams X despite manual Y` (warn) | хост игнорирует пин дольше 10 с — проверить, умеет ли хост Y |
| `codec X excluded: WxH above proven decode cap` (warn) | лесенка отфильтровала — норма |
| `decoder picked X` (debug) | факт движка (провод может врать в переходе) |
| `codec steering A -> B` | авто перевело при битых кадрах — норма |
| `codec fallback exhausted` | цепочка кончилась — плохо, смотреть сеть/хост |
| Красный баннер | пин не декодируется и рулить некуда — кнопка «назад в Авто» |
| Синий баннер | авто само перевело — информирует, ничего не надо |

### Видео и сеть
| Строка | Значение / действие |
|---|---|
| `no frames 0.7s/6s after login, re-sending options` | ранний переотпрос — норма |
| `video stalled (N s) — sent refresh` | одиночный — норма; пачками — копать сеть |
| `auto: A/B -> C/D (kbps, ping, decode/paint)` | решение лесенки; в скобках причина — читать её |
| `E 0/3` в статистике | 3 битые дельты = потери в пути |
| `(−N)` у FPS | отброшено отстающих кадров (догон) |

### Ввод, буфер, чат
| Строка | Значение |
|---|---|
| `send key #N down Legacy Ctrl+a` (debug) | комбинации и символы; Map-режим — физ. клавиши (`KeyA`), без ОС — `raw:NN` |
| `ui: hotkey …`, `ui: clipboard …`, `ui: switch display` | действия из тулбара |
| `ui: codec/quality/fps/turbo/zoom/…` | аудит остальных действий |
| `ui: chat sent/greeting/close notice` | исходящий чат и системные сообщения |

### Ошибки (красные флаги)
`decrypt failed`, `relay decode error + hex`, `SignedId unparseable`,
`connect timed out`, `host closed: …`, `manual codec X failed, no auto fallback`.

## 2. Матрица приёмки

Паузы 20–30 с между переключениями; перед кейсом — очистка журнала.
| # | Действие | PASS |
|---|---|---|
| 1–3 | Авто → VP8 / VP9 / AV1 | `ui:` + `decoder picked`, бейдж совпал за ~10 с, баннера нет |
| 4 | Ручной AV1 на хосте без AV1 | warn + красный баннер, факт в бейдже |
| 5 | «Назад в Авто» из баннера | вернулся без переподключения |
| 6–7 | Турбо вкл / выкл | пресет применился; restore точный (сверить селекты) |
| 8 | Переподключение в Авто | `auto -> X (last-good)` сразу, без перебора |
| 9 | Чат туда-обратно | окно на хосте всплыло; бейдж; позиции пережили reload |
| 10 | Обрыв 10–15 с | маркер `connection lost`, авто-реконнект, журнал цел |
| 11 | Мониторы (если есть) | `display switched`, `decoder picked` под новое разрешение |

## 3. Чтение статистики (срез за 1 секунду!)

- **Голод:** Q в сотнях мс + дропы растут + E>0 + kbps на полу. Лечить: Авто-качество, масштаб вниз.
- **Простой:** FPS низкий, но Q умеренный, дропы стоят, kbps течёт — просто статичный экран, всё хорошо.
- **Пинг** = RTT + очередь на общем сокете реле: растёт с тяжёлыми кодеками (VP8/9) — это bufferbloat, не «сеть стала хуже».
- **Нормы:** декод < 40 мс, вывод < 25 мс, Q < 120 мс.
- **Полосы лесенки:** `kbps<1200 или ping>220` → 2/15 (дно); `<3200 или >110` → 3/30; иначе 4/60. Дно-2 (1/10) — если Q>300 два тика подряд. Старт с нуля — быстрый путь (~10 с). Вверх — 6 тиков + кулдаун (против флэппинга).

## 4. География стенда (Нидерланды ↔ Хабаровск)

Норма: RTT 250–350 мс, kbps 0–1800 плавает, одиночные сталлы, пинг до 1600 на VP8/9 при забитой очереди.
Красные флаги: E пачками, дропы десятками, decode>40, Q>300 минутами на дне 1/10.
Сервер при этом idle (проверено: LA ~0.15, hbbr CPU ~0%, ошибок интерфейса 0) — тонет магистраль, не виртуалка.
